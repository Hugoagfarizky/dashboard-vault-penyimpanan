# Privacy Policy

**Berlaku sejak:** 22 November 2026

## Ringkasan

Vaultly adalah aplikasi penyimpanan pribadi berbasis browser. Aplikasi tidak memiliki akun, backend, analitik, pelacak, atau sinkronisasi cloud. Konten vault tidak dikirim oleh aplikasi ke pemelihara proyek maupun layanan pihak ketiga.

## Data yang disimpan

File yang diunggah, catatan, tautan, struktur folder, tag, dan pilihan bahasa disimpan pada browser perangkat Anda. Konten vault disimpan di IndexedDB; pilihan bahasa disimpan di localStorage. Data ini hanya tersedia pada browser dan perangkat yang digunakan untuk membuatnya.

## Cadangan dan transfer data

Saat Anda memilih **Ekspor**, browser membuat berkas ZIP dan mengunduhnya ke perangkat Anda. Saat Anda memilih **Impor**, browser membaca berkas ZIP yang Anda pilih. Kedua proses berjalan secara lokal; Vaultly tidak menerima salinan file tersebut.

## Hosting

Situs statis Vaultly disajikan melalui GitHub Pages. GitHub dapat memproses data teknis standar yang diperlukan untuk mengirimkan halaman, seperti alamat IP, jenis browser, dan catatan akses, sesuai dengan [GitHub Privacy Statement](https://docs.github.com/site-policy/privacy-policies/github-privacy-statement).

## Penghapusan data

Menghapus data situs atau penyimpanan browser untuk domain Vaultly dapat menghapus seluruh isi vault pada browser tersebut. Ekspor cadangan secara berkala jika data penting. Pemelihara proyek tidak dapat memulihkan data vault Anda karena tidak menyimpannya.

## Perubahan kebijakan

Perubahan pada kebijakan ini akan dicatat melalui commit di repository. Dengan terus menggunakan versi terbaru aplikasi setelah perubahan dipublikasikan, Anda menyetujui kebijakan yang diperbarui.
